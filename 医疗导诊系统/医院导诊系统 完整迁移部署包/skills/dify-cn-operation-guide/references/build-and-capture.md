# 从零搭建与简体中文实拍

## 一、把成品转为学员可复现的实验

- 确认对象：Workflow 还是 Chatflow，Dify 版本、语言、运行位置、可使用的模型、是否需要知识库、外部服务和实验凭据。既有部署优先使用其运行说明，避免启动另一套空 Dify 或替换原数据。
- 对照真实应用和实际导出：列节点名、类型、输入字段、实际类型、来源、输出、默认值、条件运算符、异常策略、边及分支出口；记录环境变量、会话变量和插件依赖。导出可用于作者查证，不作为学员的起始材料。
- 先把依赖展开：知识库先可用、后绑定；会话和环境变量先定义、后引用；聚合器等各来源实际建好后再配置；跨分支若必须后接线，在本步明确“先创建，至 Step N 回来连线”，并在后一步给出确切补线动作。逐条对照真实连线，不能凭布局的左右位置猜。
- 预先确认新建应用真正默认有什么。某些 Chatflow 新建时已经有 LLM 与直接回复，需在实际界面验证删除默认示例的方法；Workflow 可能直接弹出节点选择菜单。不要把这些特例硬编码为所有版本默认。
- 选择可观察的测试路径，例如只读查询、参数错误、正常成功、冲突或过期。对有写操作的服务用独立实验身份、请求号和测试资源；验证实际返回与状态，及时清理本次测试记录，不碰真实数据或历史预约。

## 二、知识库章和应用搭建章的边界

有知识库时按这个顺序记录；没有就跳过：

1. 提供真实完整原文和可上传文件，注明文件名、编码及必要来源。截图从“知识库”的实际入口开始。
2. 选择数据源、上传指定文件、核对列表中显示的名称，再进入处理。上传框的空状态与文件已就绪是不同状态；仅保留有教学价值的画面。
3. 根据本案例实际设置写分段类型、分隔符（区分字面反斜杠和真实换行）、最大长度、重叠、清洗开关、索引类型、模型及召回参数。拍分段预览与关键配置，若界面太长分上下两图。不得为套用旧案把不同配置写成固定值。
4. 保存并处理，命名，在文档列表检查“可用”和开关。现有库的截图只作为现有库状态证据，不能冒充本次上传后完成的结果。
5. 在召回测试填可复制的查询词并运行。保留真实返回，写清命中的条目和最低判断标准；无结果先查状态、索引和分段再调整。知识库章在召回测试结束。
6. “创建空白 Chatflow／Workflow”属于搭建章。知识检索节点在它自己的 Step 才进行绑定，展示查询变量的上游输出和选择的知识库。

## 三、截图操作顺序

1. 切换简体中文。在 Dify 已验证的版本中通常是头像 → 设置 → 语言 → 显示语言 → 简体中文；对照现场确认词汇。用户要求其他语言时，以本次指定语言为准。
2. 开篇成品总览关掉右侧面板、菜单和测试窗口，使用适应画布的控件（若已验证可用，也可使用快捷键），确认从起点到末端、所有分支和连接都在图内。这个成品图只用于总览。
3. 创建独立空白实验应用，避免改原工作流。记下实验应用和操作顺序。按已写的学员步骤依次进行：点击入口、添加节点、填参、绑定来源、声明输出、接线并核对。用表格记录每步填写值与截图文件名，确认以后再进入下一步。
4. 准备阶段拍创建应用类型和名称、清理默认节点后的画布、会话变量与环境变量的必要表单及保存后列表。关闭无关节点设置面板。不同类型若配置方法不同，各有对应图，例如 String 的地址和 Secret 的密钥；只用占位值截图，不截真实密钥。
5. 正文搭建图只展示当前动作或当前节点配置。较早的截图里不能出现以后才搭的节点；优先裁到当前配置面板，保留节点标题及关键字段。展示接线时仅保留当前操作涉及的上游、当前节点和出口。配置前后需要对照才放两张；不要把实质一样的两张图分别叫“选择节点”和“完成”。
6. 每个 Step 至少一张真正的完成态图。代码节点：能在一张图读清全部输入、Python 编辑区和全部输出，放这张图到本步最后；一张不够才拆分成输入、编辑区和输出的必要截图。源码全文在正文，截图无需把上百行代码都放在屏幕上。多输入时先给完整配置表，然后直接给全部输入已配置的截图，不逐个展示只有一行已绑定的中间态。
7. LLM、知识检索和 HTTP 的长配置面板，先判断哪些项目不会同时显示，再补拍局部。必要时分别拍模型／消息、召回设置、请求头与请求体、超时或异常默认值。应读得清变量与字段，不能把代码框只截成“Python3”几个字，也不能把输出顶部裁掉。
8. 先看实际截图再入稿：标题和本步一致，代码或条件确实存在，画面无加载遮罩、无别的面板、无关键字段裁切。发生截错时重拍；不能拿旧成品画布、别的版本界面、自绘图或拼接假图补齐。
9. 截图采集命名建议采用 step-NN-purpose，分阶段保存在作者 QA 目录。相同操作截图只留最清楚的一张。若平台支持更适合长面板的显示方式，完成后恢复临时显示设置。

## 四、实拍与验收证据分开

优先真正走一遍学员界面；必要时可在独立草稿中通过受支持接口分阶段配置，以取得真实的当步完成态，注明这是阶段写入，不能声称所有字段都手工重录。不能从已完成的原应用截面板后标注“从空白搭建时截图”。只有实测有记录的操作或路径才写“已验证”。

测试章提供进入运行或预览的方式、原样可复制输入、必须替换的实际值、是否沿用同一会话或请求 ID、明确成功判据与失败排查。测试截图展示本轮输入和实际结果；先等结果出现再拍。需要外部凭据而没有执行的路径写为待验收。保存后检查并确认测试没有改动正式工作流、真实患者数据或不属于本次实验的号源。
